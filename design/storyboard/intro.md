# Intro storyboard (about 18 s, skippable at any time)

| Time | Beat |
|---|---|
| 0 to 1.4 s | Darkness. |
| 1.4 s | "A single tone." A wavefront leaves the source on the stage (an optional button plays a violin note; browsers block autoplay). |
| 1.6 to 9.8 s | The wavefront expands. Where it touches, and where its six first-order wall reflections touch, seats, balcony, panels and reflectors appear: blue for reflections, amber for the direct front. |
| 8.5 to 11.2 s | Stage lights power up one by one. |
| 11.4 s | A conductor silhouette raises a hand. |
| 12.6 to 14.6 s | "Every seat hears a different hall." |
| 14.9 s | The first beat: house lights rise, the camera moves from the rear of the stalls into the editor pose, the interface wipes in. |

Skip seeks to 14.5 s. Reduced motion shows the story as four static frames. Without WebGL the poster replaces the scene.
